## Что сделано

**Бэкенд (Worker + D1), все задачи T0–T21:**
- **T0.** Stripe-клиент с закреплённой версией API `2026-09-30.endive`; живой ключ отвергается, пока нет `CIRCLE_STRIPE_LIVE=on`. Проверка подписи вебхука. Каталог по lookup_key. Миграции 0006–0012 и скрипт отката. Крон: каждые 5 минут и раз в сутки. Старая VIP-система выключена флагом `LEGACY_VIP=off`, код не удалён.
- **T5. Экономика** (§12) — чистые формулы, все примеры из брифа воспроизводятся до цента:
  - правило 2 по худшему случаю (премиальные и международные карты);
  - правила 3–5;
  - временный режим данных: доставка — оценка по классам S/M/L, для оценок минимальная маржа 25%.
  - В D1: настройки с версиями, себестоимость по вариантам (пусто ≠ 0), список Circle price, снимок каталога Shopify (только чтение), посчитанные цены с причинами отказа.
  - Админка не даёт сохранить суммы приглашения, если правило 3 не выполняется.
- **T1. Вступление и повторное вступление.**
  - Оферта, раскрытие автопродления и тексты согласий отдаёт сервер; согласия записываются с хэшем показанного текста.
  - Вступление открыто, только если включён флаг, есть тестовый ключ Stripe, есть ≥ 2 welcome-объекта ≤ $25 с доставкой и цены в Stripe совпадают с настройками.
- **T2. Вебхуки Stripe и состояния.** Вступил → продлил → платёж не прошёл → восстановил → отменил → закончилось. Повторы и события не по порядку ничего не ломают. Добавлены возвраты, споры и повтор платежа после смены карты.
- **T3/T4. Кредиты.** История с остатком. Трата через одноразовую подарочную карту Shopify: нужно подтверждение входа (step-up); при гонке двух запросов проходит только один; код показывается один раз, в D1 хранятся только последние 4 знака; если Shopify не ответил, кредиты возвращаются. Неиспользованную карту можно вернуть в кредиты.
- **T6. Цена для членов.** Автоскидка «Circle price» только для конкретных покупателей, на варианты из D1; сверка каждые 5 минут; витринный эндпоинт; аудит заказов с сигналом тебе. **В Shopify ничего не отправляет, пока нет `CIRCLE_PRICE_SYNC=on`** — его включают после спайка в dev-магазине. Запасной вариант (персональные коды) и кредиты без 2% описаны в decisions.
- **T7. Welcome piece.**
  - Наборы только из Small Pleasures, ≤ $25 с доставкой.
  - Член выбирает один раз.
  - В очереди: назначение после 14 дней; заказ на $0 создаётся только твоей кнопкой.
- **T8. Письма и крон.**
  - Напоминание за 72 часа с суммой из Stripe (с налогом).
  - Сгорание кредитов в дату льготы; при повторном вступлении они сохраняются.
  - Письма «кредиты сгорают» за 7 дней и за 1 день.
  - Напоминание о welcome piece на 3-й день.
  - Сверка со Stripe по кругу.
- **T9/T11.** Отмена в ≤ 3 шага: одно неденежное предложение по причине, кнопка «Отмена», отмена отмены (Undo). При past_due подписка заканчивается сразу. Есть страница «Membership & billing» и кнопка «Я обновил карту».
- **T12.** Возвраты и споры. Удаление аккаунта сначала отменяет подписку в Stripe; если это не удалось, аккаунт не удаляется.
- **T13/T10.** Капсулы: только существующие товары с тегом capsule, цена твоя, нужно ≥ 2 оплаченных месяца. Skip только до открытия окна; оплату и кредиты не трогает.
- **T14.** Консьерж: отвечаешь ты, без ИИ. «Your rooms»: фото в R2, файлы с EXIF отклоняются. Данные Circle включены в выгрузку и удаление аккаунта.
- **T15. Объект для членов.**
  - Всё задаёшь ты; без цены, тиража, себестоимости, окна и дат релиз не открывается.
  - Перед открытием и каждую ночь проверяется сам товар в Shopify: не опубликован ни в одном канале, активен, остаток отслеживается, продажа сверх остатка запрещена (DENY).
  - Покупка только через черновик заказа по цене из D1, −25% не применяется.
  - Один на члена; тираж не превышается даже при одновременных заявках.
  - После истечения брони можно заявиться снова; в статусе canceling нельзя.
  - Аудит обхода с сигналом тебе.
- **T16. Годовщина.** Считается по оплате, открывающей 13-й месяц. Восстановленный платёж счётчик не обнуляет; новая подписка начинает с нуля. Бюджет по правилу 4. Член подтверждает адрес в США, заказ на $0 создаёшь ты.
- **T17. Приглашение.**
  - Друг платит $40.
  - Члену +10 кредитов после второго платежа друга.
  - Одно засчитанное приглашение за квартал.
  - Совпали карта или адрес → ручная проверка.
  - Возврат или спор отменяют награду.
  - Без данных о себестоимости приглашения на паузе (правило 3).
- **T18 (API).**
  - Members: статус, баланс, следующее списание.
  - Карточка члена: журнал и счета.
  - Корректировка кредитов с обязательной заметкой; «Снять заморозку» после проигранного спора.
  - Сигналы (flags).
  - Обзор с «Credits outstanding» = сумма журнала.
- **T21. Ранний доступ** (выбрал сам, D39):

## Замечания, которые нашёл по ходу

1. **Тексты в черновой теме противоречат V2 — и там есть отзывы.** Шаблон `templates/product.json` (секции `sr-patron-tiers`, `sr-patron-faq`, `sr-patron-notes`, `sr-archival-roadmap`) говорит:
   - «Member rates of 25 to 50 percent», а у нас 25% на подходящие товары;
   - «Pause or cancel… in two clicks» и «Pausing keeps your accrued credit», а паузы нет;
   - «credit never expires», а у нас 30 дней после конца оплаченного периода;
   - «welcome vase Le Vase Livre… dispatched within 24–48 hours», а у нас закрытый набор на выбор;
   - правила капсул и «Living Library».

   Блок «Notes from the Society» — три отзыва с именами и датами и картинки `ai_vase_review_*.jpg`. Спецификация запрещает выдуманные отзывы (FTC). Шаблоны я не трогал (твоё правило). До запуска их нужно привести к одному тексту.
2. На Home (V1) тизер говорит «25% off our collections», а на странице Circle — «25% off eligible pieces» (§16). Выбери один вариант.
3. Текст раскрытия при повторном вступлении взят из §14.2 дословно, без фразы «By joining…». Пусть юрист посмотрит оба текста.
4. Члены не входят в Shopify, поэтому ввести чужую почту на чекауте всё ещё возможно (твой §19 #2). Аудит ловит только заказы со скидкой от покупателя, который не является членом сейчас.
5. Workers Free: на staging используются 2 cron-триггера, пакеты маленькие. На проде с ростом числа членов нужен Paid (B7).

**Использованные скиллы:** superpowers:test-driven-development (TDD; для T2 тесты шли сразу за кодом и проверены мутациями), shopify-plugin:shopify-admin (каждая GraphQL-операция провалидирована против 2026-07), shopify-plugin:shopify-liquid (поиск по докам; его валидатору не хватает зависимости, поэтому прогнал theme-check-node), Cloudflare — wrangler (миграции D1 сначала локально, потом на staging; деплой staging).
